# 🌱 GreenGrow – Sustainable Farming Learning Platform

GreenGrow is a web application that helps farmers learn sustainable farming practices through simple lessons, quizzes, and farming guidance. It makes agricultural learning easier and more accessible.

## ✨ Features

- 👨‍🌾 Personalized farmer dashboard
- 📚 Sustainable farming lessons and topics
- 📝 Interactive quizzes
- 🤖 Farming advisor
- 🏆 Points, achievements, and leaderboard
- 👥 Community posts and likes
- 🌐 English, Hindi, and Marathi language support
- 🔐 Secure login and registration
- 📱 Mobile-friendly design

## 🛠️ Technologies Used

- React.js and Vite
- Tailwind CSS
- Firebase Authentication
- Cloud Firestore
- GitHub and Vercel

## 🚀 Live Demo

🌐 **Try GreenGrow:** https://greengrow-2026.vercel.app/

## 🎯 Our Goal

To make sustainable farming knowledge easy to understand and accessible to farmers, encouraging environmentally friendly agricultural practices.
